# I/O

## Output

```axis
write("Hello ")       # no newline
writeln("World!")      # with newline
writeln(42)            # works with numbers
writeln(True)          # works with booleans
```

## Input

`input()` reads user input from stdin. The type expected is determined by the variable's declared type:

```axis
name: str = input()                   # read a line of text (no prompt)
x: i32 = input("Enter a number: ")   # read an integer, display prompt
```

The prompt argument is optional and can be a string literal or a string variable.

## Input Error Handling

`{var}_input_failed()` returns `True` if the preceding `input()` call for that variable failed to parse valid input. The function is named after the variable:

```axis
x: i32 = input("Enter a number: ")
when x_input_failed():
    writeln("That wasn't a number")
```

Common pattern — retry loop:

```axis
x: i32 = 0
repeat:
    x = input("Enter a number: ")
    when not x_input_failed():
        stop
    writeln("Invalid input, try again.")
```

`const` variables cannot be used with `input()` — this is a compile error.
